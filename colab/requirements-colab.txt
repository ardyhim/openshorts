# OpenShorts free-mode dependencies for Google Colab (Python 3.12/3.13, T4 GPU).
#
# IMPORTANT
#   * torch / torchvision are deliberately NOT listed here. Colab already ships
#     a CUDA-enabled pair; reinstalling the pins from requirements.txt would
#     either download a CPU build or spend 10+ minutes replacing a working one.
#   * mediapipe is optional. On Python <= 3.12 the notebook installs it
#     separately with --no-deps:
#         pip install --no-deps "mediapipe==0.10.21"
#     It needs NumPy 1.x, and the legacy mp.solutions API the app uses was
#     removed from newer releases.
#   * Python 3.13 (current Colab) has no mediapipe wheel with mp.solutions and
#     no NumPy 1.x wheels, so it uses NumPy 2 + OpenCV 4.12 and the app falls
#     back to OpenCV's Haar cascade (face_detection_compat.py).
#   * Python <= 3.12 keeps NumPy 1.26 because mediapipe 0.10.21 needs it. That
#     also means OpenCV must stay below 4.12 (4.12+ requires NumPy 2).
