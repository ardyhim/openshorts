#   * torch / torchvision are deliberately NOT listed here. Colab already ships

#     removed from newer releases. The notebook therefore pins numpy<2 below.
#   * Installing NumPy 1.26 also means OpenCV must stay below 4.12 (4.12+
#     requires NumPy 2). OpenCV 4.10/4.11 are the last 1.x-compatible wheels.
