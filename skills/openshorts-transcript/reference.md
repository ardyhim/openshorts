# OpenShorts transcript reference

The skill's three JSON contracts are copies of contracts the app already
produces. If the app changes, change this skill and run
`tests/test_openshorts_transcript_skill.py`; it compares this skill against
`manual_clip_selection.py` and `free_tools.py`.

## Inputs

| Input | How it is read |
|---|---|
| `youtube.com/watch?v=...`, `youtu.be/...`, `/shorts/...`, `/live/...`, `/embed/...`, bare 11-char ID | YouTube's existing manual or auto captions via yt-dlp. No audio download, no ASR. |
| `.srt` | SubRip cues, including multi-line text, HTML tags and cue numbers. |
| `.vtt` | WebVTT cues; `NOTE`, `STYLE` and `REGION` blocks are skipped. |
| `.txt` | Timestamped lines in `[00:01:23] text`, `00:01:23 - text` or `00:01:23 --> 00:01:25 text` form. Plain text is only usable with `--format text`. |
| `.json` | An export, a pipeline transcript, a YouTube tool response, or a bare segments list. |
| `-` | Reads stdin and sniffs JSON, SRT/VTT, timestamped TXT, then plain text. |

`--lang` selects the YouTube caption track (`en`, `es`, `en-orig`, ...).
`--language` sets the output language code. When neither the input nor
`--language` supplies one, the script uses `py3langid` if installed and
`unknown` otherwise. `--duration` is required before a timestamped TXT whose
last line has no end time can become export or pipeline JSON.

## Format: export (default)

`openshorts.transcript-export.v1`, generated by
`manual_clip_selection.build_transcript_export()` and downloaded by the app's
"Download transcript" action (`GET /api/jobs/{job_id}/analysis/export`).

```json
{
  "schema": "openshorts.transcript-export.v1",
  "generated_at": "2026-10-30T12:00:00Z",
  "job_id": null,
  "language": "en",
  "duration_seconds": 213.0,
  "clip_duration_seconds": { "min": 15.0, "max": 60.0 },
  "recommended_clip_count": { "min": 3, "max": 6 },
  "prompt": "You are a senior short-form video editor. ...",
  "output_contract": {
    "schema": "openshorts.clip-selection.v1",
    "clips": [
      {
        "start": "number (absolute seconds)",
        "end": "number (absolute seconds)",
        "score": "integer 0-100 (optional, default 70)",
        "title": "optional, max 100 chars",
        "hook": "optional, max 10 words",
        "reason": "optional, one sentence",
        "description_tiktok": "optional",
        "description_instagram": "optional"
      }
    ]
  },
  "transcript": {
    "text": "Full transcript text.",
    "segments": [
      { "start": 1.36, "end": 3.04, "text": "First cue." }
    ]
  },
  "windows": [
    {
      "id": "window_001",
      "start": 1.36,
      "end": 93.72,
      "text": "Consecutive segments grouped for navigation."
    }
  ]
}
```

- Segment values are rounded to 3 decimals.
- Empty or non-positive-length segments are dropped.
- `duration_seconds` falls back to the last segment end when the source
  duration is unknown.
- `clip_duration_seconds` comes from `CLIP_MIN_SECONDS` / `CLIP_MAX_SECONDS`
  (default 15-60), or `--min-seconds` / `--max-seconds`.
- `recommended_clip_count` follows `clip_selection.clip_count_targets()`.
- `windows` follow `clip_selection.build_transcript_windows()` (roughly 90 s,
  30 s overlap, snapped to segment boundaries).
- `prompt` is the exact handoff prompt from `manual_clip_selection._prompt()`.

## Format: pipeline

The word-level contract returned by `transcribe_backends.transcribe_media()`
and stored as `source_transcript.json` / `.transcript_checkpoint.json`.

```json
{
  "text": "Full punctuated transcript.",
  "language": "en",
  "segments": [
    {
      "start": 0.0,
      "end": 2.5,
      "text": "Hello world.",
      "words": [
        { "word": " Hello", "start": 0.0, "end": 0.4 },
        { "word": " world.", "start": 0.4, "end": 0.9 }
      ]
    }
  ]
}
```

Invariants from `transcribe_backends.py`:

- `words[].word` carries a **leading space** on a true word start.
- Continuation fragments (no leading space) belong to the previous word, but
  this skill emits already-merged words.
- Numerics are native JSON floats, segments are chronological, and timestamps
  are absolute file time.
- `words` is never empty for a non-empty segment; caption/subtitle sources get
  estimated per-word timings. See the accuracy note in `SKILL.md`.

## Format: youtube

The response from `GET /api/tools/youtube-transcript`
(`free_tools.fetch_transcript()` + the route's `cached` flag).

```json
{
  "video_id": "dQw4w9WgXcQ",
  "title": "Video title",
  "channel": "Channel name",
  "duration": 213,
  "languages": [
    { "code": "en", "kind": "manual", "request": "en", "name": "English" },
    { "code": "en", "kind": "auto", "request": "en-orig",
      "name": "English (auto-generated)" }
  ],
  "language": "en",
  "kind": "manual",
  "segments": [
    { "start": 1.36, "dur": 1.68, "text": "First cue." }
  ],
  "cached": false
}
```

- `kind` is `manual` (creator captions) or `auto` (YouTube speech
  recognition). Machine translations are never offered.
- `languages[].request` is what `--lang` accepts: the plain code for a manual
  track, `<code>-orig` for the auto track.
- Auto-caption overlaps are clamped so SRT cues cannot collide, exactly as
  `free_tools.parse_json3()` does.
- `--format youtube` requires a YouTube input or a YouTube tool JSON; a plain
  SRT has no video metadata.

## Format: text and SRT

These mirror `dashboard/tools/transcript.js`:

- `text` without `--timestamps`: cues joined with spaces, runs of spaces
  collapsed.
- `text --timestamps`: `[m:ss] cue` per line (`h:mm:ss` past an hour).
- `srt`: numbered cues; `HH:MM:SS,mmm --> HH:MM:SS,mmm`; the end is the cue end,
  or at least 0.5 s when a cue is shorter.

## Errors

The script prints `error: <message>` to stderr and exits 2 for user errors.

| Code | Meaning |
|---|---|
| `bad_url` | The YouTube link did not contain one video ID. |
| `no_captions` | The video has no readable manual or automatic captions. |
| `unavailable` | Private, removed, age-restricted or region-blocked video. |
| `youtube_blocked` | YouTube did not answer the server; retry or pass `--cookies`. |
| `bad_json` | The JSON is not one of the supported transcript shapes. |
| `no_timestamps` | The requested JSON/SRT format needs timed cues. |
| `ambiguous_duration` | A TXT's last cue has no end; pass `--duration`. |
| `bad_duration` | `--duration` is before the last segment end. |
